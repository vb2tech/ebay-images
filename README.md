# eBay listing photos

Photos of graded comics, used as image links in eBay bulk listings.

## Layout

```
photos/<Series>/<Series>-<issue>_<Grader>-<grade>[_<Variant>]_<cert>/<SKU>-<n>.jpg
```

- **Folder name** = what the book is (series, issue, grade, variant, cert number).
- **File name** = original SKU (`<Grader>-<cert>-<photo number>.jpg`). It matches the `Custom label (SKU)` column in the eBay upload file. Don't rename files; eBay listings link to these exact paths.
- `index.csv` lists every book with its folder, for searching.
